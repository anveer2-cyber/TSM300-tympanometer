# Oscilla TSM-300 조사 메모

제조사: Inmedico A/S (덴마크), 상표 Oscilla. 스크리닝용 임피던스 청력검사기.

## 확인된 사실

출처는 TSM-300 사용 설명서(Instructions for Use, 21쪽)와 제품 브로슈어입니다.

### 연결

- 뒷면 `SERIAL` 단자는 RS-232이며 PC 전송 또는 시리얼 프린터 출력에 쓴다. `PRINTER` 단자는 병렬 프린터용이다.
- PC와는 널모뎀 케이블로 연결한다. PC에 시리얼 포트가 없으면 USB-시리얼 변환기를 쓸 수 있다.
- 전용 PC 프로그램은 AudioConsole(별매)이다.

### 전송 방식

- 오른쪽 화살표 키가 출력 키다. `MENU` -> `Right key` 에서 `PRINT` / `TRANSMIT` 을 고른다.
- `TRANSMIT` 상태에서 오른쪽 키를 누르면 화면의 검사가 PC로 전송된다. 검사 후 자동 전송된다는 설명은 없다.
- 전원을 켤 때 장비가 시리얼 포트로 식별 키(identification key)를 자동으로 보낸다. PC 프로그램이 tympanometer 모드로 바뀌는 데 쓴다.
- `Printer Port` 가 `Serial` 이면 식별 키를 보내지 않는다.

### 저장과 결과 항목

- 메모리에 20개 측정을 저장한다. ID 위치마다 양쪽 귀의 그래프와 수치를 모두 저장한다.
- 화면 수치: `MID EAR PRESS`(daPa), `EAR VOLUME`(ml), `COMPLIANCE`(ml), `TYMP WIDTH`(daPa).
- 반사 검사: 동측, 500 / 1000 / 2000 / 3000 / 4000 Hz, 105 dB SPL. 컴플라이언스 변화가 0.05 ml 를 넘으면 반사 있음.

### 사양

- 프로브 톤 226 Hz, 85 dB SPL
- 압력 범위 +200 ~ -300 daPa
- 용적 범위 0.1 ~ 6.0 ml
- 교정 캐비티 0.5 / 2.0 / 5.0 ml

### 실제 장비에서 확인한 통신 (2026-11-26)

- 통신 설정은 9600 bps, 8N1 이다. USB-시리얼 어댑터(COM5)로 확인했다.
- 전원을 켜면 식별 키가 두 줄로 온다. 각 줄은 내용 76바이트(남는 자리는 `00` 으로 채움) 뒤에 `0A 0D` 가 붙어 78바이트다.
  - 첫 줄: `ID TSM-300 SCREENING`
  - 둘째 줄: `KEY6349`
- 줄 끝이 `0D 0A` 가 아니라 `0A 0D` 순서다.
- 전원을 끄고 켤 때 맨 앞에 잡음 `00` 한 바이트가 들어온다.

### 검사 결과 전송 형식

`TRANSMIT` 상태에서 오른쪽 키를 누르면 장비가 PC의 응답을 기다리지 않고 바로 보낸다. 전송에 0.7 ~ 1.4초가 걸린다.

전송은 레코드의 나열이다. 레코드 하나는 이름표 4글자(ASCII), 길이 2바이트(리틀 엔디언), 그 길이만큼의 값으로 이루어진다. 맨 끝에는 길이 없이 `STOP` 4글자만 온다.

| 이름표 | 길이 | 내용 |
| --- | --- | --- |
| `PAID` | 2 | 장비 메모리의 ID 번호 |
| `LT02`, `RT02` | 160 | 왼쪽, 오른쪽 고막운동도 곡선. 점 하나가 1바이트 |
| `LMEP`, `RMEP` | 2 | 중이 압력 (daPa, 부호 있는 정수) |
| `LPVO`, `RPVO` | 2 | 외이도 용적 (0.001 ml 단위) |
| `LCOM`, `RCOM` | 2 | 컴플라이언스 (0.001 ml 단위) |
| `LTWI`, `RTWI` | 2 | 폭 (daPa) |
| `LR05` ... `LR40`, `RR05` ... `RR40` | 40 | 반사 검사 곡선. 숫자는 주파수(05 = 500 Hz, 40 = 4000 Hz). 검사한 주파수만 온다 |
| `DNAM` | 7 | 장비 이름 `TSM-300` |
| `CODE` | 4 | 식별 키의 숫자 `6349` |
| `STOP` | 없음 | 전송 끝 |

측정하지 않은 귀는 곡선과 수치가 모두 0 이고 반사 레코드가 없다. 길이는 측정 없음 431바이트, 한쪽 귀와 반사 5개 661바이트, 양쪽 귀와 반사 10개 891바이트였다.

곡선 값의 해석은 장비 화면 사진, 화면에 표시된 수치와 대조해서 정했다.

- **고막운동도 세로축**: `ml = 값 / 64 - 0.5`. 곡선 최고점이 장비가 보낸 컴플라이언스와 일치한다 (138 -> 1.656 ml, 장비 표시 1.66 ml). 마지막 점(+200 daPa)이 0 ml 가 되도록 장비가 보정해서 보낸다.
- **고막운동도 가로축**: 점 사이 간격 3.125 daPa, 마지막 점이 +200 daPa, 첫 점이 -296.875 daPa. 장비가 보내는 중이 압력과 폭은 모두 3.125 의 배수에서 소수점을 버린 값이다 (0, 6, -6 daPa 와 71, 84, 103 daPa 는 각각 0, 6.25, -6.25, 71.875, 84.375, 103.125). 중이 압력이 +6, -6 daPa 인 측정에서도 곡선 최고점이 그 위치에 놓였다.
- **정상 범위 사각형**: 장비 화면은 고막운동도 위에 압력 -150 ~ +100 daPa, 컴플라이언스 0.2 ~ 1.5 ml 사각형을 그린다. 화면 사진의 LCD 점을 세어 확인했다. 화면 세로 1점이 1/18 ml 이고 사각형 위쪽 변은 27번째 줄(1.5 ml), 아래쪽 변은 4번째 줄(0.22 ml)이다. 아래쪽은 점 간격 때문에 0.2 와 0.25 를 구분할 수 없어 0.2 로 잡았다.
- **원래 프로그램(AudioConsole) 출력물과 대조**: 2021년 출력물 세 장의 수치도 같은 규칙을 따른다. 편평한 결과의 중이 압력 -296 daPa 는 곡선 첫 점(-296.875)이고, 폭 240, 59, 68, 90, 50, 96 daPa 는 모두 3.125 의 배수에서 소수점을 버린 값이다. 출력물은 반사 그래프를 각 고막운동도 바로 아래에 두고, 반사 축을 0 에서 -0.2 ml 로 적는다(반사는 컴플라이언스를 줄이므로 음수).
- **반사 곡선**: `ml = 값 * 0.2 / 256`. 장비 화면의 반사 그래프 전체 높이가 0.2 ml 이고 값 254 가 그 높이를 가득 채운다. 화면 눈금에서 읽은 값이라 고막운동도 축보다 근거가 약하다.

### 프린터 출력 (대안 경로)

- 프린터 종류: `MATRIX`(Epson 호환), `IBM PRO`, `THERMO`(시리얼 감열 프린터), `HP`(PCL).
- `Printer Port` 를 `Serial` 로 바꾸면 시리얼 포트로 인쇄 데이터가 나온다. `TRANSMIT` 해독이 되었으므로 지금은 쓸 필요가 없다.

## 확인되지 않은 것

- 커넥터 종류와 핀 배열.
- `KEY6349` 의 숫자가 장비마다 다른 값인지.
- `LT02` 의 `02` 가 무엇을 뜻하는지.
- 반사 곡선의 가로축(시간) 단위.
- 정상 범위 사각형의 아래쪽 경계가 0.2 ml 인지 0.25 ml 인지.

## 교정이 틀어졌을 때의 증상

2026-11-26 에 이 장비는 정상 귀에서 외이도 용적 9.30 ml, 8.39 ml 를 표시했다 (사양 범위는 0.1 ~ 6.0 ml). 곡선의 압력 위치와 폭은 정상이었지만 ml 단위 값이 전체적으로 부풀려져 있었고, 반사 곡선은 눈금 끝까지 닿으며 불규칙했다. `MENU` -> `Calib cavity` 로 다시 교정한 뒤에는 용적 0.96 / 0.74 ml, 컴플라이언스 0.52 / 0.62 ml 로 돌아왔고 반사 곡선도 깨끗해졌다.

## 주의

- `MENU` -> `Calib cavity` 는 교정값을 바꾸는 메뉴다. 캡처 시험에 캐비티를 쓸 때는 이 메뉴에 들어가지 말고 일반 측정 화면에서 프로브만 캐비티에 꽂는다.
- `MENU` -> `Clear data` 는 저장된 측정을 지운다.
