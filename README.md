# TSM300-tympanometer

Oscilla TSM-300 임피던스 청력검사기(tympanometer)의 검사 결과를 검사 직후 PC로 가져와, 환자 정보와 함께 A4 결과지(JPG)로 저장하는 프로그램입니다. MRS Resonance 청력검사기의 순음 · 어음 · 음장 검사 결과도 받습니다([청력검사기](#청력검사기-mrs-resonance)).

## 설치 (Windows)

### exe 파일로 (Python 없이)

[TSM300.exe 내려받기](https://github.com/anveer2-cyber/TSM300-tympanometer/releases/latest/download/TSM300.exe)

내려받은 `TSM300.exe` 를 바탕 화면처럼 찾기 쉬운 곳에 두고 더블클릭합니다. 설치 과정은 없습니다.

- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 서명하지 않은 프로그램이라 나오는 경고입니다.
- 파일 하나에 모든 것이 들어 있어서 켜지는 데 시간이 조금 걸립니다.
- 결과는 `%APPDATA%\TSM300\results` 에 저장됩니다. 창의 [저장 폴더 열기]로 엽니다. 다른 폴더를 쓰려면 [설정] → 장비 · 저장에서 바꿉니다.
- 설정도 `%APPDATA%\TSM300` 에 있습니다. exe 를 새 것으로 바꾸거나 다른 폴더로 옮겨도 설정과 결과는 그대로입니다.
- 업데이트는 창 오른쪽 위 [업데이트]를 누릅니다. 새 버전이 있으면 [지금 설치]로 받아 바꿔 넣고, [다시 켜기]를 누르면 새 버전으로 켜집니다. 받는 동안에도 검사 결과는 그대로 받습니다. 인터넷이 되어야 합니다.
- exe 는 64비트입니다. 매직차트 DB 에 직접 연결하려면 이 PC 에 64비트 ODBC 데이터 원본이 있어야 합니다. 예진이 서버를 거치면 상관없습니다.

아래 설명의 `python -m tsm300` 자리에 `TSM300.exe` 를 쓰면 됩니다. exe 는 명령 프롬프트 창 없이 뜨므로, 글로 답하는 명령은 `TSM300.exe ports > ports.txt` 처럼 파일로 받아 봅니다.

### Python 으로 (3.9 이상)

```bash
python -m pip install --upgrade https://github.com/anveer2-cyber/TSM300-tympanometer/archive/refs/heads/claude/cool-hamilton-bdp178.zip
```

`python` 명령이 없다고 나오면 `py -m pip ...`, `py -m tsm300` 으로 실행합니다.

## 장비 쪽 준비

- `MENU` -> `Right key` -> `TRANSMIT`
- `MENU` -> `Printer setup` -> `Printer Port` -> `Parallel`
- 장비 뒷면 `SERIAL` 단자와 PC를 케이블로 연결

## 실행

```bash
python -m tsm300
```

창이 뜨고 USB-시리얼 포트에 자동으로 연결합니다. 케이블을 나중에 꽂거나 다른 USB 단자로 옮겨도 몇 초 안에 다시 찾아 연결합니다. 창은 한 번에 하나만 뜨고, 위쪽에 지금 연결된 포트가 항상 표시됩니다.

포트를 자동으로 둘 때의 규칙입니다. 같은 PC 에 있는 다른 장비(청력검사기 등)의 포트를 잘못 열지 않으려는 것입니다.

- 장비가 한 번 응답하면 그 USB-시리얼 케이블을 기억합니다. 다음부터는 그 케이블만 엽니다. 다른 USB 단자에 꽂아 포트 이름이 바뀌어도 찾아갑니다.
- 기억한 케이블이 빠져 있으면 다른 포트를 대신 열지 않고 기다립니다. 케이블을 다른 것으로 바꿨다면 [설정]에서 포트를 한 번 골라 주세요.
- 아직 기억이 없을 때는 USB-시리얼 케이블이 하나면 그 포트를 쓰고, 여러 개면 아무 것도 열지 않고 [설정]에서 골라 달라고 알려 줍니다.
- USB-시리얼 케이블이 없으면 PC 의 COM1 같은 자체 포트를 엽니다. 블루투스 포트는 열지 않습니다.
- 장비가 응답한 포트는 그 포트가 있는 동안 계속 씁니다. 다른 USB 장치를 나중에 꽂아도 넘어가지 않습니다.

[설정] → 장비 · 저장에서 포트를 직접 고르면 그 포트만 씁니다. 그 포트가 안 보이면 다른 포트로 바꾸지 않고 기다립니다.

**처음 한 번**: [설정] → 병원 정보에 병원 이름, 주소, 전화번호를 넣습니다. 결과지 맨 위와 맨 아래에 인쇄됩니다.

### 바탕 화면 바로가기 (Python 으로 설치했을 때)

```bash
python -m tsm300 shortcut
```

바탕 화면에 **TSM-300 임피던스 검사** 바로가기가 생깁니다. 더블클릭하면 명령 프롬프트 창 없이 프로그램이 뜹니다. 결과는 이 명령을 실행한 폴더의 `results` 에 저장되므로, 결과를 모아 둘 폴더에서 실행해 주세요. 프로그램을 업데이트해도 바로가기는 그대로 쓸 수 있습니다.

창으로 실행했을 때 예상하지 못한 오류가 나면 내용이 `%APPDATA%\TSM300\error.log` 에 남습니다. exe 도 같습니다.

### 검사 순서

1. 환자를 정합니다. 방법은 세 가지입니다.
   - **오늘 검사 오더**: 목록에서 환자를 누릅니다. 이미 검사한 환자는 ✓ 가 붙고 흐리게 보입니다.
   - **차트번호 조회**: 차트번호를 넣고 [조회]를 누르거나 Enter 를 칩니다.
   - **직접 입력**: 차트번호, 이름, 성별, 생년월일을 손으로 넣습니다.

   목록이나 조회로 찾은 환자는 "이 환자가 맞습니까?" 확인을 거친 뒤 채워집니다. 위쪽에 "다음 검사는 ○○○ 환자로 저장됩니다"가 표시됩니다.
2. 검사를 마치고 장비에서 `->` 키를 누릅니다.
3. 결과지가 화면에 나타나고 저장 폴더에 바로 저장됩니다. 받은 결과는 이 단계에서 이미 PC 에 남으므로 잃어버리지 않습니다.
4. 결과지를 확인하고, 필요하면 검사일시나 메모를 고친 뒤 **[출력]**을 누릅니다.

환자 정보를 넣지 않았거나 앞 환자 정보가 그대로 남아 있을 때는, 결과를 환자 정보 없이 저장해 두고 알려 줍니다. 환자 정보를 확인한 뒤 **이 환자 정보로 저장**을 누르면 결과지에 반영됩니다. 앞 환자의 이름이 다음 환자 결과에 잘못 붙지 않게 하려는 장치입니다.

### 출력: 인쇄, 보내기, 보관

화면 아래 **[출력]** 하나로 세 가지를 한 번에 합니다. 각각 따로 하는 버튼도 옆에 있습니다.

| 버튼 | 하는 일 |
| --- | --- |
| **[출력]** | 인쇄 → 컴퓨터에 보관 → 상쾌한캡처로 보내기를 차례로 합니다 |
| [인쇄...] | 프린터를 골라 A4 한 장으로 인쇄만 합니다 |
| [상쾌한캡처로 보내기] | 상쾌한캡처로 보내기만 합니다 (설정에 주소와 키를 넣었을 때 보입니다) |
| [컴퓨터에 보관] | 결과지와 로데이터를 날짜별 보관 폴더에 정리해 두기만 합니다 |

- [출력]을 누르면 프린터 선택 창이 뜹니다. 여기서 취소하면 보관과 보내기도 하지 않습니다.
- 고치던 검사일시, 메모, 특이사항은 [출력]할 때 먼저 저장됩니다. 검사일시와 메모는 인쇄물, 보관본, 보낸 결과지에 똑같이 들어가고, 특이사항은 보관본의 JSON 에만 들어갑니다.
- 상쾌한캡처에 이미 들어간 결과지는 [출력]을 다시 눌러도 또 보내지 않습니다. 인쇄와 보관만 다시 합니다.
- 환자 정보가 없는 결과지는 [출력]할 때 한 번 묻고, 상쾌한캡처로는 보내지 않습니다.
- 상쾌한캡처를 쓰지 않으면 버튼 이름이 [출력 (인쇄 + 보관)]으로 바뀝니다.

**보관 폴더**는 날짜별로 정리됩니다. 한 검사에 파일 세 개가 같은 이름으로 들어갑니다.

```
보관\2026-11\2026-11-26\00512_홍길동_1430.jpg    결과지 (원본)
보관\2026-11\2026-11-26\00512_홍길동_1430.json   로데이터: 수치와 곡선
보관\2026-11\2026-11-26\00512_홍길동_1430.bin    로데이터: 장비가 보낸 그대로
```

- 폴더의 날짜와 이름의 시각은 검사일시입니다. 같은 환자를 같은 분에 두 번 검사했으면 뒤의 것에 `_2` 가 붙습니다.
- 보관한 뒤에 메모, 검사일시, 환자를 고치면 보관본도 따라 바뀝니다. 환자나 날짜가 바뀌면 보관본의 자리와 이름도 옮겨집니다.
- [지난 결과 열기...]에서 보관본을 골라도 됩니다. 그 결과의 원래 파일을 열어 주므로 고치고 다시 출력할 수 있습니다.
- 위치는 [설정] → 장비 · 저장의 보관 폴더에서 바꿉니다. 비워 두면 저장 폴더 안의 `보관` 입니다. [보관 폴더 열기]로 엽니다.

### 결과지 고치기

화면에 떠 있는 결과지는 왼쪽 아래 **화면의 결과지 고치기**에서 고칩니다.

- **검사일시**: 처음에는 결과를 받은 시각입니다. 검사한 날짜나 시각이 다르면 고치고 [검사일시 · 메모 저장]을 누릅니다. 내일 이후 날짜는 고를 수 없습니다. 나이는 검사일 기준으로 다시 계산됩니다.
- **메모**: 결과지 맨 아래 메모 칸에 인쇄됩니다. 다섯 줄까지 들어가고, 넘치면 화면에서 알려 줍니다.
- **특이사항 (결과지에 안 나옴)**: 직원끼리 알아 둘 것을 적습니다. 결과지에는 인쇄하지 않고, 상쾌한캡처로도 보내지 않습니다. 결과의 JSON 파일(`remarks`)과 보관본에만 저장되고, [지난 결과 열기...]로 열면 다시 보이고 고칠 수 있습니다. 임피던스 · 청력검사 결과 모두 같습니다. [검사일시 · 메모 저장]을 누르면 함께 저장됩니다.
- **환자 정보**: 환자 정보 칸을 고친 뒤 [이 환자 정보로 저장]을 누릅니다. 이미 다른 환자로 저장된 결과지는 확인을 거쳐 바꿉니다.
- **저장을 누르지 않아도** 다음 검사를 받거나, 인쇄하거나, 상쾌한캡처로 보내거나, 창을 닫을 때 고치던 검사일시, 메모, 특이사항은 그 결과에 저장됩니다.
- **청력검사 값**: 청력검사 결과지는 [검사 값 고치기...]로 역치 · 어음 값도 고칩니다([청력검사기](#검사-값-고치기와-직접-입력) 참고).
- **지난 결과**: [지난 결과 열기...]로 저장된 결과를 다시 불러 같은 방법으로 고칩니다.
- **결과지 열기**: [결과지 열기]는 JPG 파일을 PC 의 기본 사진 프로그램으로 엽니다.
- **상쾌한캡처로 이미 보낸 뒤에 고치면** 고친 결과지는 저절로 다시 보내지 않습니다. [상쾌한캡처로 보내기]를 누르면 새 장으로 들어가므로, 먼저 보낸 것은 상쾌한캡처에서 지워야 합니다. 자주 고치신다면 자동 보내기를 끄고, 고친 뒤에 보내는 편이 깔끔합니다.

긴 이름이나 주소는 글자를 줄여서 넣고, 그래도 넘치는 환자 이름은 두 줄로 인쇄합니다. 옆 칸을 침범하지 않습니다.

### 저장이 안 될 때

- **방금 받은 결과를 저장하지 못했습니다**: 저장 폴더가 없어졌거나 디스크가 찼을 때 나옵니다. 장비가 보낸 데이터는 `%APPDATA%\TSM300\unsaved` 에 보관되고, 환자 정보는 그대로 남습니다. 저장 폴더를 확인한 뒤 장비에서 `->` 키를 다시 누르면 됩니다.
- **고친 내용을 저장하지 못했습니다**: 결과지를 다른 프로그램에서 열어 두어 파일이 잠겨 있을 때 나옵니다. 그 창을 닫고 다시 저장합니다. 그 전까지 원래 결과지는 그대로 있습니다. 그 상태에서 다음 결과가 오면 고치던 검사일시와 메모를 화면에 그대로 보여 주니, [지난 결과 열기...]로 앞 결과를 열어 다시 넣으면 됩니다.

### 설정

창 오른쪽 위 [설정]에서 정합니다. 값은 `%APPDATA%\TSM300\설정.json` 에 저장되고 저장소에는 들어가지 않습니다.

| 탭 | 정하는 것 |
| --- | --- |
| 병원 정보 | 결과지에 인쇄할 병원 이름, 주소, 전화번호. 비워 둔 칸은 인쇄되지 않습니다 |
| 장비 · 저장 | 장비 포트(보통 자동), 받은 결과가 자동 저장되는 저장 폴더, 출력한 결과를 날짜별로 정리하는 보관 폴더. 쓸 수 없는 폴더는 저장되지 않고 알려 줍니다 |
| 환자 조회 | 전자차트에서 환자 정보와 오늘 검사 오더를 읽어 오는 방법 (쓰지 않아도 됩니다) |
| 상쾌한캡처 | 결과지를 상쾌한캡처로 보내는 주소와 키 (쓰지 않아도 됩니다) |
| 청력검사기 | MRS Resonance 청력검사기 쓰기, 연결(USB 또는 연습용 모의 장비), 주고받은 바이트 기록, [연결 시험] (쓰지 않아도 됩니다) |
| 프로그램 정보 | 버전, 설정 파일과 오류 기록의 위치, 사용한 공개 소프트웨어 |

병원 정보를 바꾸면 화면에 떠 있는 결과지와 그 뒤에 받는 결과지에 적용됩니다. 이미 상쾌한캡처로 보낸 결과지는 그대로 둡니다. 환자 조회와 상쾌한캡처를 쓰지 않는 병원은 환자 정보를 직접 넣고 [인쇄...]나 JPG 파일로 쓰면 됩니다.

**환자 조회**는 둘 중 하나를 고릅니다. 고르지 않으면 직접 입력만 됩니다.

| 방법 | 필요한 것 | 되는 것 |
| --- | --- | --- |
| 매직차트 DB | 이 PC 에 매직차트 ODBC 연결(SQL Anywhere)이 있어야 합니다 | 차트번호 조회, 오늘 검사 오더 |
| 예진이 서버 | 예진이 v4.52.0 이상, 서버 주소와 TSM300 토큰 | 차트번호 조회, 오늘 검사 오더 |

예진이 서버의 주소와 토큰은 서버 PC 콘솔에서 `m` + Enter 를 치면 나옵니다. VNG 용 토큰과는 다른 TSM300 전용 토큰입니다.

읽기만 하고, 주민번호는 생년월일과 성별을 알아내는 앞 7자리만 DB 안에서 잘라 읽습니다.


**상쾌한캡처**는 받는 PC 주소와 키를 넣습니다.

1. 진료실 PC 의 상쾌한캡처(0.4.66 이상) 설정 → 휴대폰 → [검사 장비 추가 (결과지 보내기 전용)]에서 장비를 추가하고 키를 받습니다. 키는 그때 한 번만 보입니다.
2. TSM300 [설정]에 받는 PC 주소와 키를 넣고 [연결 시험]을 누릅니다.
3. "결과지를 저장하면 바로 상쾌한캡처로 보내기"를 켜면 자동으로 보냅니다. 끄면 [상쾌한캡처로 보내기]를 눌러 보냅니다.

상쾌한캡처는 차트번호와 이름이 전자차트와 같을 때만 받습니다. 생년월일을 넣었으면 그것도 같아야 합니다. 받지 않으면 이유가 화면에 나옵니다.

- 보내는 번호는 화면에 보이는 차트번호뿐입니다. 전자차트 내부번호는 보내지 않습니다.
- 결과지는 다시 압축되지 않고 보낸 파일 그대로 저장됩니다(사진 이력, image_data, 사진 서버).
- 같은 결과지를 다시 보내도 두 번 들어가지 않습니다. 연결이 안 됐거나 받는 쪽 오류였다면 나중에 다시 보내면 됩니다.
- 조회로 찾은 환자는, 상쾌한캡처가 저장했다고 알려 온 환자와 내부번호가 같은지 보내고 난 뒤 한 번 더 견줍니다. 다르면 확인하라고 알려 줍니다.

### 상쾌한캡처에 잘못 들어갔을 때

TSM300 에서는 지울 수 없고, 상쾌한캡처에서 정리합니다. 가능하면 결과지를 받은 진료실 PC 에서 합니다.

1. 결과지가 잘못 들어간 환자를 차트번호로 엽니다.
2. 사진 이력에서 검사일 아래의 `중이검사` 카드를 오른쪽 클릭합니다.
3. 다른 환자의 것이면 "이 사진만 다른 환자로 이동…", 필요 없으면 "삭제…"를 고릅니다. 지운 것은 `trash` 에 남아 되살릴 수 있습니다.

TSM300 에서 환자를 바꿔 다시 저장하면 새 결과지가 새 환자에게 따로 들어가므로, 앞 환자에게 들어간 것은 "삭제…"로 지우면 됩니다.

### 저장되는 파일

받은 결과는 누르는 것 없이 모두 **저장 폴더**에 자동으로 저장됩니다. 검사 한 번마다 받은 시각과 차트번호를 이름으로 한 파일 세 개가 생깁니다. 파일 이름에 환자 이름은 넣지 않습니다. 이름의 시각은 장비에서 받은 때이므로 검사일시를 고쳐도 바뀌지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `20261126_211205_00512.jpg` | A4 결과지 (300 dpi, 2480×3508). 환자 정보, 양쪽 고막운동도와 등골근 반사, 측정값 표, 메모 |
| `20261126_211205_00512.json` | 검사 종류(`exam`: 임피던스는 `tymp`, 청력검사기는 `hearing`), 받은 시각, 검사일시, 병원 정보, 환자 정보, 메모, 특이사항(`remarks`, 인쇄 안 함), 수치, 곡선 데이터, 상쾌한캡처로 보낸 기록 |
| `20261126_211205_00512.bin` | 장비가 보낸 원본 데이터 |

[출력]이나 [컴퓨터에 보관]을 누른 결과는 여기에 더해 **보관 폴더**에 날짜별, 환자 이름으로 정리된 사본이 생깁니다(위의 "출력" 참고). 저장 폴더는 잃어버리지 않기 위한 곳이고, 보관 폴더는 사람이 찾아보기 위한 곳입니다.

## 청력검사기 (MRS Resonance)

순음 · 어음 · 음장 청력검사도 같은 창에서 받습니다. MRS Resonance 청력검사기(R27A · R37A · R35C 등)를 USB 로 연결하고, 검사를 기기에 저장한 뒤 **[청력검사기에서 받기]**를 누릅니다. 결과는 임피던스 결과와 같은 폴더에 같은 방식으로 저장되고, 같은 [출력] · [지난 결과 열기...] · 상쾌한캡처 보내기를 씁니다.

- 기기의 검사는 **읽기만** 합니다. 지우거나 기기 설정을 바꾸는 명령은 프로그램 안에서 막혀 있습니다.
- 제조사 프로그램(MDS)은 그 PC 에서 **닫아 둡니다**. 기기는 한 번에 한 프로그램만 열 수 있습니다.
- MRS 드라이버는 깔려 있어야 합니다. MDS 를 설치할 때 함께 깔립니다. 다른 것은 더 설치하지 않습니다.
- USB 연결은 Windows 에서만 됩니다.

### 처음 한 번 (병원에서)

1. MDS 를 닫고, 청력검사기를 켜고, USB 선으로 PC 에 꽂습니다. 장비에서 **[Connect to PC]**를 누릅니다.
2. 명령 프롬프트에서 아래를 실행합니다. 기기를 찾아 저장된 검사를 읽어 보고, 무엇을 읽었는지 적습니다. 읽기만 합니다.

   ```bash
   TSM300.exe hearing-check > 청력검사기_점검.txt
   ```

   만든 `청력검사기_점검.txt` 와, 저장 폴더 안 `청력검사기_기록` 폴더에 생긴 `.txt` 파일을 보관해 주세요. 실제 기기와 처음 주고받은 기록이라, 문제가 생기면 이것으로 원인을 찾습니다.
3. 창을 열고 [설정] → **청력검사기**에서 "청력검사기(MRS Resonance) 쓰기"를 켜고, 연결은 **USB**, "주고받은 바이트 기록 남기기"는 켜 둡니다. [연결 시험]을 누르면 "연결됨: MRS Resonance R37A (일련번호 …)"가 나옵니다.

연결은 **모의 장비**로도 고를 수 있습니다. 견본 환자의 검사가 들어 있는 가짜 청력검사기입니다. 실제 기기 없이 받는 순서를 연습할 때 씁니다. 실제 검사에는 쓰지 마세요.

### 받는 순서

R27A 를 쓸 때 늘 지킬 것 (장비 설명서 기준):

- **장비를 끄기 전에 받습니다.** 화면의 곡선은 전원을 끄면 지워집니다.
- **다음 환자 전에 장비의 곡선을 지웁니다** (TEST MANAGEMENT → DELETE ALL). 안 지우면 앞 환자 곡선에 다음 환자 점이 같이 찍혀, 프로그램이 두 사람을 가려낼 수 없습니다.
- 받은 뒤 같은 곡선에 점을 더 찍고 다시 받으면, 바뀐 검사가 새 검사로 한 번 더 보입니다.


1. 환자를 고릅니다. 임피던스와 같습니다(오늘 검사 오더, 차트번호 조회, 직접 입력).
2. 청력검사기에서 검사를 마치고 기기에 저장합니다.
3. 장비에서 **[Connect to PC]**를 누르고, **[청력검사기에서 받기]**를 누릅니다. 순서는 바뀌어도 됩니다. [받기]를 먼저 누르면 30초 동안 "장비에서 [Connect to PC]를 눌러 주세요 (남은 시간 n초)"가 나오며 기다립니다. 받는 동안에도 창은 그대로 쓸 수 있고, 임피던스 결과도 그대로 받습니다.
4. 받은 검사 창이 뜹니다.
   - **새 검사만** 보입니다. 기기(R27A)는 화면의 곡선을 전원을 끌 때까지 들고 있어서, 받을 때마다 옛 검사도 함께 옵니다. 결과지로 만든 검사는 기억해 두고 다음부터 빼고 보여 줍니다. 다시 만들려면 [이미 받은 검사도 보기]를 켭니다.
   - 검사는 **기기에 입력된 환자별**로 묶여 있습니다. 기기에 적힌 이름 · 생년월일이 그대로 보입니다. 화면의 환자와 생년월일이 다르면 ⚠ 가 붙습니다. 기기 쪽 이름은 결과지에 쓰지 않습니다.
   - 가장 최근 기기 환자의 새 검사가 처음부터 체크되어 있습니다. 이 환자의 검사만 남기고 체크합니다. 체크한 검사가 결과지 **한 장**이 됩니다(순음 + 어음 + 고주파).
   - 맨 위 "○○○ 환자의 검사입니다"가 체크되어 있어야 그 환자로 저장됩니다. 화면의 환자가 앞 검사에 쓴 정보이면 체크가 꺼져 있습니다. 같은 환자면 체크하세요. 체크하지 않으면 환자 정보 없이 저장되고, 나중에 [이 환자 정보로 저장]으로 넣습니다.
5. [결과지 만들기]를 누르면 저장되고 결과지가 화면에 나옵니다. 검사일시는 **받은 시각**입니다. 기기는 검사 날짜를 보내지 않습니다. 다르면 [화면의 결과지 고치기]에서 고칩니다.
6. 출력은 임피던스와 같습니다. 상쾌한캡처로는 `hearing`(순음청력) 검사로 보냅니다.

### 보청기 착용 전 · 후 음장검사를 한 장에

보청기 없이 한 음장검사와, 보청기를 끼고 다시 한 음장검사를 결과지 한 장에 넣습니다.

1. 받은 검사 창에서 두 검사를 다 체크합니다.
2. 보청기를 끼고 한 검사(음장만 있는 검사)의 **[보청기 착용]**을 체크합니다. 음장만 있는 검사에만 이 칸이 있습니다.
3. 그 검사의 음장 결과가 결과지의 **음장 보청기** 줄과 그래프의 `A` 기호로 들어가고, 보청기 없이 한 것은 **음장** 줄과 `S` 기호로 들어갑니다. 평균도 각각 나옵니다. 어음 음장검사도 같습니다.

같은 귀의 같은 결과(예: 음장 오른쪽)가 두 검사에 있으면 저장하지 않고 알려 줍니다. 뒤의 것이 보청기 착용 검사면 [보청기 착용]을 체크하고, 아니면 하나만 고릅니다.

### 결과지

- 양쪽 청력도(오른쪽은 빨강 · 왼쪽 파랑, ASHA 기호: 기도 ○ ×, 차폐 △ □, 골도 < >, 차폐 [ ], 음장 S, 보청기 A, 불쾌역치 U, 쾌적역치 M, 이명 T, 무반응은 기호 아래 화살표). 표 아래 "기호:" 줄에 그 결과지에 그린 기호만 뜻과 함께 적습니다(ASHA 는 보청기 착용 음장 기호를 정해 두지 않아, 결과지마다 밝혀 두게 되어 있습니다).
- 귀마다 역치 표: 기도 · 골도 · 음장 · 음장 보청기 · 불쾌역치 · 쾌적역치 중 검사한 것, 차폐한 주파수는 바로 아래 "차폐" 줄.
- **평균(6분법)** = (500 + 2×1k + 2×2k + 4k) ÷ 6, 소수점 아래는 버립니다(예전 프로그램과 같음). 기도 · 골도 · 음장 · 음장 보청기마다 나옵니다. `↑` 는 무반응 주파수가 들어간 평균(실제는 그 이상), `*` 는 검사하지 않은 주파수를 빼고 낸 평균, 표의 `↓` 는 무반응입니다.
- 어음 표: SRT, 최고 명료도, 그때 강도, 정답 / 단어, 차폐 × 기도 · 골도 · 음장 · 음장 보청기 × 좌우.
- 고주파(8~20 kHz) 검사를 넣으면 작은 표가 따로 붙습니다.
- 이명도검사를 넣었으면 어음 표 아래에 이명 표가 붙습니다(아래 "이명도검사").
- 메모 칸과 맨 아래 장비 일련번호는 임피던스 결과지와 같습니다. 한 장에 넣을 것이 많으면 그래프와 표가 조금 작아집니다.

`TSM300.exe hearing-demo 견본.jpg` 는 모의 장비의 견본 검사로 결과지를 그려 줍니다.

### 검사 값 고치기와 직접 입력

청력검사 값은 자유롭게 고칠 수 있고, 청력검사기 없이 처음부터 손으로 넣을 수도 있습니다. 두 가지 모두 같은 창을 씁니다.

- **[검사 값 고치기...]** (왼쪽 [화면의 결과지 고치기] 아래): 화면의 청력검사 결과지 값을 고칩니다. [지난 결과 열기...]로 연 결과, 직접 입력한 결과도 됩니다.
- **[직접 입력...]** ([청력검사기에서 받기] 옆): 빈 창이 열립니다. 값을 넣고 [저장]을 누르면 받은 결과와 똑같이 저장되고 결과지가 나옵니다. 환자는 [청력검사기에서 받기]와 같은 규칙입니다: 창 위의 "○○○ 환자의 검사입니다"가 체크되어 있어야 그 환자로 저장되고, 앞 검사에 쓴 환자 정보면 체크가 꺼져 있습니다. 검사일시는 [검사일시 · 메모] 탭에서 정합니다(처음에는 지금 시각).

**이명도검사**: 창의 "이명" 탭에 귀마다 이명 주파수, 이명 크기, 청력역치, 차폐 잡음 역치, 최소 차폐 크기, 잔류 억제, 억제 특성을 적힌 그대로 넣습니다(`1500`, `28 dB`, `85 dB (o)`, `Mo51dB` 처럼 아무 글이나 됩니다. 억제 특성은 고르거나 칩니다). 기기의 이명 검사는 받지 않으므로 늘 손으로 넣습니다. 하나라도 넣으면 결과지에 이명 표가 붙고, 이명 주파수와 크기가 읽히면 청력도에 `T` 로 표시합니다. 크기는 dB HL 로 보고, `10 dB SL` 처럼 SL 이면 그 주파수의 기도 역치에 더해 그립니다. SPL 이면 표에만 나옵니다. 이명만 넣고 [직접 입력...]으로 결과지를 만들어도 됩니다. 오늘 검사 오더에는 이명도검사(F6346) 오더가 "이명" 으로 나오고, 이명 값을 넣은 청력검사 결과지를 만들면 ✓ 가 붙습니다.

창에서 넣는 법:

| 탭 | 넣는 것 |
| --- | --- |
| 순음 · 음장 | 귀마다 표 하나. 줄은 기도 · 골도 · 음장 · 음장 보청기 · 불쾌역치 · 쾌적역치, 각 줄 아래 "차폐" 줄. 칸은 125 Hz ~ 8 kHz. 오른쪽 끝에 6분법 평균이 넣는 대로 바로 나옵니다 |
| 어음 | 기도 · 골도 · 음장 · 음장 보청기마다, 귀마다 SRT 와 점 10개(강도, 정답률, 차폐, 맞힌 단어 수, 단어 수) |
| 고주파 | 고주파 검사를 받은 결과에만 있습니다 |
| 이명 | 귀마다 이명도검사 일곱 칸 (위 "이명도검사") |
| 검사일시 · 메모 | 검사일시, 메모(인쇄됨), 특이사항(인쇄 안 됨) |

- 칸을 누르고 숫자(dB HL)를 칩니다. Tab 이나 Enter 로 옆 칸으로 갑니다. Delete 로 고른 칸을 지웁니다. 지우면 검사하지 않은 것이 됩니다.
- **무반응**: 숫자 뒤에 `n` 을 붙입니다(`90n` → `90↓`, 한글 자판이면 `ㅜ` 도 됩니다). 칸을 골라 오른쪽 클릭 → "무반응 (↓) 표시 · 풀기"도 됩니다.
- **차폐**: 역치 아래 "차폐" 줄에 차폐 크기(dB)를 넣습니다. 차폐했지만 크기를 모르면 `?` 를 넣습니다. 무반응 + 차폐도 됩니다(`90n` 아래 `70`).
- 기기가 보내지 않은 줄(예: 불쾌역치)도 채우면 결과지에 그 곡선이 생깁니다.
- 어음 정답률을 비우고 맞힌 단어 수 · 단어 수를 넣으면 정답률은 맞힌 수 ÷ 단어 수로 채웁니다.
- [저장]을 누르면 잘못 넣은 칸(범위 −10 ~ 120 dB, 정답률 0 ~ 100 %, 맞힌 수가 단어 수보다 많음, 역치 없이 차폐만 있음 등)을 빨갛게 표시하고 이유를 알려 주며 저장하지 않습니다. 고친 뒤 다시 [저장]을 누릅니다.
- [취소]는 아무것도 바꾸지 않습니다. 넣던 값이 있으면 버릴지 한 번 묻습니다.

저장하면:

- 결과지를 다시 그리고 저장 폴더의 파일과 보관본을 바꿉니다. 메모 고치기와 같습니다. 평균도 고친 값으로 다시 계산합니다.
- **결과지에는 고친 값이 표시 없이 그대로 인쇄됩니다.** 처음부터 그 값으로 받은 것과 똑같은 결과지입니다. 직접 입력한 결과지는 맨 아래 장비 일련번호 자리가 비어 있습니다.
- 기기가 보낸 값은 버리지 않습니다. `.bin`(기기가 보낸 그대로)은 바뀌지 않고, JSON 에 고친 값과 원래 값이 나란히 남습니다(`corrections`). 다시 열면 `.bin` 을 다시 읽고 고친 값을 그 위에 얹습니다. 직접 입력한 결과는 `.bin` 이 빈 파일이고 JSON 에 `"source": "manual"` 이 적힙니다.
- 상쾌한캡처에 이미 보낸 결과지는 저절로 다시 보내지 않습니다(메모를 고칠 때와 같음, [결과지 고치기](#결과지-고치기) 참고).
- 값을 고치는 창이 열려 있는 동안 새 결과가 와도 받은 결과는 그대로 저장됩니다. 그때 [저장]한 값은 고치던 앞 결과지에 들어가고, 화면에서 알려 줍니다.

### 저장되는 것

임피던스와 같은 이름 규칙으로 저장 폴더에 세 파일이 생깁니다.

| 파일 | 내용 |
| --- | --- |
| `20261127_103005_00512.jpg` | A4 결과지 |
| `20261127_103005_00512.json` | `exam: "hearing"`. 주파수마다 역치 · 차폐 · 무반응, 3 · 4 · 6분법 평균, 어음 점마다 강도 · 정답률 · 정답 수, SRT, 기기에 입력된 환자, 패킷 원본(16진수), 손으로 고친 값과 원래 값, 특이사항 |
| `20261127_103005_00512.bin` | 기기가 보낸 패킷 그대로 (기기 환자 + 검사). 값을 고쳐도 바뀌지 않습니다. 직접 입력한 결과는 빈 파일 |

JSON 의 칸은 [docs/hearing/원자료_형식.md](docs/hearing/원자료_형식.md) 에 있습니다. 나중에 상쾌한캡처 서버로 원자료를 보내 장애진단서 · 산재 서류를 채울 때 그대로 쓰는 약속입니다.

어느 검사를 결과지로 만들었는지는 설정 폴더의 `청력검사기_받은검사.json` 에 기억합니다. 지우면 기기의 모든 검사가 다시 새 검사로 보입니다.

### 주고받은 바이트 기록

[설정] → 청력검사기의 "주고받은 바이트 기록 남기기"가 켜져 있으면(처음부터 켜짐), 받을 때마다 저장 폴더 안 `청력검사기_기록` 폴더에 파일이 하나 생깁니다.

```
청력검사기_기록\20261127_103005.txt
2026-11-27 10:30:05.012  PC>     16  4b43001016040100000000000000136b
2026-11-27 10:30:05.030  <DEV    20  4b49000e…
```

이 PC 가 보낸 것(`PC>`)과 기기가 보낸 것(`<DEV`)을 시각, 바이트 수, 16진수로 모두 적습니다. 받기가 안 될 때 화면에 이 파일의 위치가 함께 나옵니다. 문제를 물어볼 때 이 파일을 보내 주세요. 기록에는 기기에 입력된 환자 이름이 들어 있으니 다른 곳에 올리지 마세요.

### 안 될 때

| 화면에 나오는 말 | 할 일 |
| --- | --- |
| USB 에서 청력검사기를 찾지 못했습니다 | 장비에서 [Connect to PC]를 누르고 다시 받습니다. 그래도 없으면 기기 전원과 USB 선, 장치 관리자의 청력검사기(MRS 드라이버, MDS 설치)를 확인합니다 |
| 청력검사기를 다른 프로그램이 쓰고 있습니다 | MDS 를 닫고 다시 누릅니다 |
| 청력검사기가 답하지 않습니다 | 장비에서 [Connect to PC]를 누르고 다시 받습니다. 계속되면 USB 선을 다시 꽂습니다. **기기를 끄면 화면의 검사가 지워지니**, 끄기 전에 인쇄나 USB PDF 로 남깁니다 |
| 청력검사기와 주고받다가 멈췄습니다 | USB 선을 다시 꽂고 다시 누릅니다. 기기의 검사는 그대로 있습니다 |
| 다 보냈다는 신호 없이 조용해졌습니다 | 찾는 검사가 목록에 없으면 한 번 더 받습니다 |
| 새 검사가 없습니다 | 기기에 저장했는지 확인합니다. 이미 결과지로 만든 검사는 [이미 받은 검사도 보기]로 봅니다 |
| … 결과가 두 검사에 들어 있습니다 | 보청기를 끼고 한 검사면 [보청기 착용]을 체크하고, 아니면 하나만 고릅니다 |
| 방금 받은 결과를 저장하지 못했습니다 | 저장 폴더를 확인하고 [청력검사기에서 받기]를 다시 누릅니다. 그 검사는 새 검사로 다시 보입니다 |
| USB 연결은 Windows 에서만 됩니다 | Windows PC 에서 씁니다 |

**오늘 검사 오더**: 청력검사기를 켜면 순음청력(F6341 · F6340), 언어청각(F6300), 음장(F0341~F0344), 이명도검사(F6346) 오더도 목록에 나오고, "검사" 칸에 `중이` · `청력` · `이명` 과 끝난 검사의 ✓ 가 붙습니다. 매직차트 DB 로 읽는 PC 는 바로 되고, 예진이 서버를 거치는 PC 는 서버가 청력검사 코드를 보내 줄 때부터 됩니다([docs/hearing/예진이_오더_요청.md](docs/hearing/예진이_오더_요청.md)).

## 그 밖의 명령

| 명령 | 하는 일 |
| --- | --- |
| `python -m tsm300 listen` | 창 없이 명령 프롬프트에서 결과를 받아 저장 (환자 정보 없음) |
| `python -m tsm300 decode 파일.bin --chart 00512 --name 홍길동 --tested "2026-11-26 14:30"` | 저장해 둔 원본 데이터로 결과지를 다시 만들기 |
| `python -m tsm300 shortcut` | 바탕 화면 바로가기 만들기 |
| `TSM300.exe update` | 새 버전이 있으면 받아서 바꿔 넣기 (창의 [업데이트]와 같은 일). `--check` 는 확인만 |
| `python -m tsm300 ports` | 시리얼 포트 목록 |
| `python -m tsm300 capture` | 장비가 보내는 바이트를 해독 없이 그대로 기록 (형식 분석용) |
| `TSM300.exe hearing-check` | 청력검사기를 USB 로 찾아 저장된 검사를 읽어 보고, 주고받은 바이트를 모두 기록 (읽기만). `--simulator` 는 모의 장비로 |
| `TSM300.exe hearing-demo 견본.jpg` | 모의 장비의 견본 검사로 청력검사 결과지를 그려 봄 |

장비와 통신 형식에 대해 알아낸 내용은 [docs/device-notes.md](docs/device-notes.md) 에, 청력검사기의 통신 절차와 결과 구조는 [docs/hearing/](docs/hearing/) 에 있습니다.

## 개발

```bash
python -m pip install -e ".[dev]"
```

```bash
python -m pytest
```

exe 는 Windows 에서 만듭니다.

```bash
python -m pip install . pyinstaller
```

```bash
python tools/build_exe.py
```

`dist\TSM300.exe` 가 생깁니다. `tools\check_exe.ps1` 은 만든 exe 의 버전, 결과지 그리기, 창 뜨기, 스스로 업데이트하기를 확인합니다. GitHub 에 올리면 같은 일이 자동으로 돌고, 버전 번호(`src/tsm300/__init__.py`)가 새것이면 그 exe 가 Releases 에 올라갑니다.

`tests/data` 의 파일은 실제 장비에서 받은 전송입니다. 청력검사기는 실제 기기 자료 없이, 지어낸 패킷(`src/tsm300/hearing/samples.py`)과 모의 장비(`simulator.py`)로 시험합니다. 제조사의 프로그램 · 견본 패킷은 이 저장소에 넣지 않습니다. 병원 DB 와 상쾌한캡처는 테스트에서 가짜(`tests/fakes.py`)로 대신합니다. `src/tsm300/links.py` 는 병원의 VNGLive 프로그램에서 쓰는 조회와 전송 코드를 옮겨 온 것입니다. 화면 테스트는 `QT_QPA_PLATFORM=offscreen` 환경변수를 주면 화면 없이 돌아갑니다.
