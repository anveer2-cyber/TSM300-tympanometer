# TSM300-tympanometer

Oscilla TSM-300 임피던스 청력검사기(tympanometer)의 검사 결과를 검사 직후 PC로 가져와, 환자 정보와 함께 A4 결과지(JPG)로 저장하는 프로그램입니다.

## 설치 (Windows)

### exe 파일로 (Python 없이)

[TSM300.exe 내려받기](https://github.com/anveer2-cyber/TSM300-tympanometer/releases/latest/download/TSM300.exe)

내려받은 `TSM300.exe` 를 바탕 화면처럼 찾기 쉬운 곳에 두고 더블클릭합니다. 설치 과정은 없습니다.

- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 서명하지 않은 프로그램이라 나오는 경고입니다.
- 파일 하나에 모든 것이 들어 있어서 켜지는 데 시간이 조금 걸립니다.
- 결과는 `%APPDATA%\TSM300\results` 에 저장됩니다. 창의 [저장 폴더 열기]로 엽니다. 다른 폴더를 쓰려면 [설정] → 장비 · 저장에서 바꿉니다.
- 설정도 `%APPDATA%\TSM300` 에 있습니다. exe 를 새 것으로 바꾸거나 다른 폴더로 옮겨도 설정과 결과는 그대로입니다.
- 업데이트는 창 오른쪽 위 [업데이트]를 누릅니다. 새 버전이 있으면 [지금 설치]로 받아 바꿔 넣고, [다시 켜기]를 누르면 새 버전으로 켜집니다. 받는 동안에도 검사 결과는 그대로 받습니다. 인터넷이 되어야 합니다.
- exe 는 64비트입니다. 매직차트 DB 에 직접 연결하려면 이 PC 에 64비트 ODBC 데이터 원본이 있어야 합니다. 예진이 서버를 거치면 상관없습니다.

아래 설명의 `python -m tsm300` 자리에 `TSM300.exe` 를 쓰면 됩니다. exe 는 명령 프롬프트 창 없이 뜨므로, 글로 답하는 명령은 `TSM300.exe ports > ports.txt` 처럼 파일로 받아 봅니다.

### Python 으로 (3.9 이상)

```bash
python -m pip install --upgrade https://github.com/anveer2-cyber/TSM300-tympanometer/archive/refs/heads/claude/cool-hamilton-bdp178.zip
```

`python` 명령이 없다고 나오면 `py -m pip ...`, `py -m tsm300` 으로 실행합니다.

## 장비 쪽 준비

- `MENU` -> `Right key` -> `TRANSMIT`
- `MENU` -> `Printer setup` -> `Printer Port` -> `Parallel`
- 장비 뒷면 `SERIAL` 단자와 PC를 케이블로 연결

## 실행

```bash
python -m tsm300
```

창이 뜨고 USB-시리얼 포트에 자동으로 연결합니다. 케이블을 나중에 꽂거나 다른 USB 단자로 옮겨도 몇 초 안에 다시 찾아 연결합니다. 창은 한 번에 하나만 뜨고, 위쪽에 지금 연결된 포트가 항상 표시됩니다.

포트를 자동으로 둘 때의 규칙입니다. 같은 PC 에 있는 다른 장비(청력검사기 등)의 포트를 잘못 열지 않으려는 것입니다.

- 장비가 한 번 응답하면 그 USB-시리얼 케이블을 기억합니다. 다음부터는 그 케이블만 엽니다. 다른 USB 단자에 꽂아 포트 이름이 바뀌어도 찾아갑니다.
- 기억한 케이블이 빠져 있으면 다른 포트를 대신 열지 않고 기다립니다. 케이블을 다른 것으로 바꿨다면 [설정]에서 포트를 한 번 골라 주세요.
- 아직 기억이 없을 때는 USB-시리얼 케이블이 하나면 그 포트를 쓰고, 여러 개면 아무 것도 열지 않고 [설정]에서 골라 달라고 알려 줍니다.
- USB-시리얼 케이블이 없으면 PC 의 COM1 같은 자체 포트를 엽니다. 블루투스 포트는 열지 않습니다.
- 장비가 응답한 포트는 그 포트가 있는 동안 계속 씁니다. 다른 USB 장치를 나중에 꽂아도 넘어가지 않습니다.

[설정] → 장비 · 저장에서 포트를 직접 고르면 그 포트만 씁니다. 그 포트가 안 보이면 다른 포트로 바꾸지 않고 기다립니다.

**처음 한 번**: [설정] → 병원 정보에 병원 이름, 주소, 전화번호를 넣습니다. 결과지 맨 위와 맨 아래에 인쇄됩니다.

### 바탕 화면 바로가기 (Python 으로 설치했을 때)

```bash
python -m tsm300 shortcut
```

바탕 화면에 **TSM-300 임피던스 검사** 바로가기가 생깁니다. 더블클릭하면 명령 프롬프트 창 없이 프로그램이 뜹니다. 결과는 이 명령을 실행한 폴더의 `results` 에 저장되므로, 결과를 모아 둘 폴더에서 실행해 주세요. 프로그램을 업데이트해도 바로가기는 그대로 쓸 수 있습니다.

창으로 실행했을 때 예상하지 못한 오류가 나면 내용이 `%APPDATA%\TSM300\error.log` 에 남습니다. exe 도 같습니다.

### 검사 순서

1. 환자를 정합니다. 방법은 세 가지입니다.
   - **오늘 검사 오더**: 목록에서 환자를 누릅니다. 이미 검사한 환자는 ✓ 가 붙고 흐리게 보입니다.
   - **차트번호 조회**: 차트번호를 넣고 [조회]를 누르거나 Enter 를 칩니다.
   - **직접 입력**: 차트번호, 이름, 성별, 생년월일을 손으로 넣습니다.

   목록이나 조회로 찾은 환자는 "이 환자가 맞습니까?" 확인을 거친 뒤 채워집니다. 위쪽에 "다음 검사는 ○○○ 환자로 저장됩니다"가 표시됩니다.
2. 검사를 마치고 장비에서 `->` 키를 누릅니다.
3. 결과지가 화면에 나타나고 저장 폴더에 바로 저장됩니다. 받은 결과는 이 단계에서 이미 PC 에 남으므로 잃어버리지 않습니다.
4. 결과지를 확인하고, 필요하면 검사일시나 메모를 고친 뒤 **[출력]**을 누릅니다.

환자 정보를 넣지 않았거나 앞 환자 정보가 그대로 남아 있을 때는, 결과를 환자 정보 없이 저장해 두고 알려 줍니다. 환자 정보를 확인한 뒤 **이 환자 정보로 저장**을 누르면 결과지에 반영됩니다. 앞 환자의 이름이 다음 환자 결과에 잘못 붙지 않게 하려는 장치입니다.

### 출력: 인쇄, 보내기, 보관

화면 아래 **[출력]** 하나로 세 가지를 한 번에 합니다. 각각 따로 하는 버튼도 옆에 있습니다.

| 버튼 | 하는 일 |
| --- | --- |
| **[출력]** | 인쇄 → 컴퓨터에 보관 → 상쾌한캡처로 보내기를 차례로 합니다 |
| [인쇄...] | 프린터를 골라 A4 한 장으로 인쇄만 합니다 |
| [상쾌한캡처로 보내기] | 상쾌한캡처로 보내기만 합니다 (설정에 주소와 키를 넣었을 때 보입니다) |
| [컴퓨터에 보관] | 결과지와 로데이터를 날짜별 보관 폴더에 정리해 두기만 합니다 |

- [출력]을 누르면 프린터 선택 창이 뜹니다. 여기서 취소하면 보관과 보내기도 하지 않습니다.
- 고치던 검사일시와 메모는 [출력]할 때 먼저 저장되어 인쇄물, 보관본, 보낸 결과지에 똑같이 들어갑니다.
- 상쾌한캡처에 이미 들어간 결과지는 [출력]을 다시 눌러도 또 보내지 않습니다. 인쇄와 보관만 다시 합니다.
- 환자 정보가 없는 결과지는 [출력]할 때 한 번 묻고, 상쾌한캡처로는 보내지 않습니다.
- 상쾌한캡처를 쓰지 않으면 버튼 이름이 [출력 (인쇄 + 보관)]으로 바뀝니다.

**보관 폴더**는 날짜별로 정리됩니다. 한 검사에 파일 세 개가 같은 이름으로 들어갑니다.

```
보관\2026-11\2026-11-26\00512_홍길동_1430.jpg    결과지 (원본)
보관\2026-11\2026-11-26\00512_홍길동_1430.json   로데이터: 수치와 곡선
보관\2026-11\2026-11-26\00512_홍길동_1430.bin    로데이터: 장비가 보낸 그대로
```

- 폴더의 날짜와 이름의 시각은 검사일시입니다. 같은 환자를 같은 분에 두 번 검사했으면 뒤의 것에 `_2` 가 붙습니다.
- 보관한 뒤에 메모, 검사일시, 환자를 고치면 보관본도 따라 바뀝니다. 환자나 날짜가 바뀌면 보관본의 자리와 이름도 옮겨집니다.
- [지난 결과 열기...]에서 보관본을 골라도 됩니다. 그 결과의 원래 파일을 열어 주므로 고치고 다시 출력할 수 있습니다.
- 위치는 [설정] → 장비 · 저장의 보관 폴더에서 바꿉니다. 비워 두면 저장 폴더 안의 `보관` 입니다. [보관 폴더 열기]로 엽니다.

### 결과지 고치기

화면에 떠 있는 결과지는 왼쪽 아래 **화면의 결과지 고치기**에서 고칩니다.

- **검사일시**: 처음에는 결과를 받은 시각입니다. 검사한 날짜나 시각이 다르면 고치고 [검사일시 · 메모 저장]을 누릅니다. 내일 이후 날짜는 고를 수 없습니다. 나이는 검사일 기준으로 다시 계산됩니다.
- **메모**: 결과지 맨 아래 메모 칸에 인쇄됩니다. 다섯 줄까지 들어가고, 넘치면 화면에서 알려 줍니다.
- **환자 정보**: 환자 정보 칸을 고친 뒤 [이 환자 정보로 저장]을 누릅니다. 이미 다른 환자로 저장된 결과지는 확인을 거쳐 바꿉니다.
- **저장을 누르지 않아도** 다음 검사를 받거나, 인쇄하거나, 상쾌한캡처로 보내거나, 창을 닫을 때 고치던 검사일시와 메모는 그 결과에 저장됩니다.
- **지난 결과**: [지난 결과 열기...]로 저장된 결과를 다시 불러 같은 방법으로 고칩니다.
- **결과지 열기**: [결과지 열기]는 JPG 파일을 PC 의 기본 사진 프로그램으로 엽니다.
- **상쾌한캡처로 이미 보낸 뒤에 고치면** 고친 결과지는 저절로 다시 보내지 않습니다. [상쾌한캡처로 보내기]를 누르면 새 장으로 들어가므로, 먼저 보낸 것은 상쾌한캡처에서 지워야 합니다. 자주 고치신다면 자동 보내기를 끄고, 고친 뒤에 보내는 편이 깔끔합니다.

긴 이름이나 주소는 글자를 줄여서 넣고, 그래도 넘치는 환자 이름은 두 줄로 인쇄합니다. 옆 칸을 침범하지 않습니다.

### 저장이 안 될 때

- **방금 받은 결과를 저장하지 못했습니다**: 저장 폴더가 없어졌거나 디스크가 찼을 때 나옵니다. 장비가 보낸 데이터는 `%APPDATA%\TSM300\unsaved` 에 보관되고, 환자 정보는 그대로 남습니다. 저장 폴더를 확인한 뒤 장비에서 `->` 키를 다시 누르면 됩니다.
- **고친 내용을 저장하지 못했습니다**: 결과지를 다른 프로그램에서 열어 두어 파일이 잠겨 있을 때 나옵니다. 그 창을 닫고 다시 저장합니다. 그 전까지 원래 결과지는 그대로 있습니다. 그 상태에서 다음 결과가 오면 고치던 검사일시와 메모를 화면에 그대로 보여 주니, [지난 결과 열기...]로 앞 결과를 열어 다시 넣으면 됩니다.

### 설정

창 오른쪽 위 [설정]에서 정합니다. 값은 `%APPDATA%\TSM300\설정.json` 에 저장되고 저장소에는 들어가지 않습니다.

| 탭 | 정하는 것 |
| --- | --- |
| 병원 정보 | 결과지에 인쇄할 병원 이름, 주소, 전화번호. 비워 둔 칸은 인쇄되지 않습니다 |
| 장비 · 저장 | 장비 포트(보통 자동), 받은 결과가 자동 저장되는 저장 폴더, 출력한 결과를 날짜별로 정리하는 보관 폴더. 쓸 수 없는 폴더는 저장되지 않고 알려 줍니다 |
| 환자 조회 | 전자차트에서 환자 정보와 오늘 검사 오더를 읽어 오는 방법 (쓰지 않아도 됩니다) |
| 상쾌한캡처 | 결과지를 상쾌한캡처로 보내는 주소와 키 (쓰지 않아도 됩니다) |
| 프로그램 정보 | 버전, 설정 파일과 오류 기록의 위치, 사용한 공개 소프트웨어 |

병원 정보를 바꾸면 화면에 떠 있는 결과지와 그 뒤에 받는 결과지에 적용됩니다. 이미 상쾌한캡처로 보낸 결과지는 그대로 둡니다. 환자 조회와 상쾌한캡처를 쓰지 않는 병원은 환자 정보를 직접 넣고 [인쇄...]나 JPG 파일로 쓰면 됩니다.

**환자 조회**는 둘 중 하나를 고릅니다. 고르지 않으면 직접 입력만 됩니다.

| 방법 | 필요한 것 | 되는 것 |
| --- | --- | --- |
| 매직차트 DB | 이 PC 에 매직차트 ODBC 연결(SQL Anywhere)이 있어야 합니다 | 차트번호 조회, 오늘 검사 오더 |
| 예진이 서버 | 예진이 v4.52.0 이상, 서버 주소와 TSM300 토큰 | 차트번호 조회, 오늘 검사 오더 |

예진이 서버의 주소와 토큰은 서버 PC 콘솔에서 `m` + Enter 를 치면 나옵니다. VNG 용 토큰과는 다른 TSM300 전용 토큰입니다.

읽기만 하고, 주민번호는 생년월일과 성별을 알아내는 앞 7자리만 DB 안에서 잘라 읽습니다.


**상쾌한캡처**는 받는 PC 주소와 키를 넣습니다.

1. 진료실 PC 의 상쾌한캡처(0.4.66 이상) 설정 → 휴대폰 → [검사 장비 추가 (결과지 보내기 전용)]에서 장비를 추가하고 키를 받습니다. 키는 그때 한 번만 보입니다.
2. TSM300 [설정]에 받는 PC 주소와 키를 넣고 [연결 시험]을 누릅니다.
3. "결과지를 저장하면 바로 상쾌한캡처로 보내기"를 켜면 자동으로 보냅니다. 끄면 [상쾌한캡처로 보내기]를 눌러 보냅니다.

상쾌한캡처는 차트번호와 이름이 전자차트와 같을 때만 받습니다. 생년월일을 넣었으면 그것도 같아야 합니다. 받지 않으면 이유가 화면에 나옵니다.

- 보내는 번호는 화면에 보이는 차트번호뿐입니다. 전자차트 내부번호는 보내지 않습니다.
- 결과지는 다시 압축되지 않고 보낸 파일 그대로 저장됩니다(사진 이력, image_data, 사진 서버).
- 같은 결과지를 다시 보내도 두 번 들어가지 않습니다. 연결이 안 됐거나 받는 쪽 오류였다면 나중에 다시 보내면 됩니다.
- 조회로 찾은 환자는, 상쾌한캡처가 저장했다고 알려 온 환자와 내부번호가 같은지 보내고 난 뒤 한 번 더 견줍니다. 다르면 확인하라고 알려 줍니다.

### 상쾌한캡처에 잘못 들어갔을 때

TSM300 에서는 지울 수 없고, 상쾌한캡처에서 정리합니다. 가능하면 결과지를 받은 진료실 PC 에서 합니다.

1. 결과지가 잘못 들어간 환자를 차트번호로 엽니다.
2. 사진 이력에서 검사일 아래의 `중이검사` 카드를 오른쪽 클릭합니다.
3. 다른 환자의 것이면 "이 사진만 다른 환자로 이동…", 필요 없으면 "삭제…"를 고릅니다. 지운 것은 `trash` 에 남아 되살릴 수 있습니다.

TSM300 에서 환자를 바꿔 다시 저장하면 새 결과지가 새 환자에게 따로 들어가므로, 앞 환자에게 들어간 것은 "삭제…"로 지우면 됩니다.

### 저장되는 파일

받은 결과는 누르는 것 없이 모두 **저장 폴더**에 자동으로 저장됩니다. 검사 한 번마다 받은 시각과 차트번호를 이름으로 한 파일 세 개가 생깁니다. 파일 이름에 환자 이름은 넣지 않습니다. 이름의 시각은 장비에서 받은 때이므로 검사일시를 고쳐도 바뀌지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `20261126_211205_00512.jpg` | A4 결과지 (300 dpi, 2480×3508). 환자 정보, 양쪽 고막운동도와 등골근 반사, 측정값 표, 메모 |
| `20261126_211205_00512.json` | 검사 종류(`exam`: 지금은 `tymp` 뿐), 받은 시각, 검사일시, 병원 정보, 환자 정보, 메모, 수치, 곡선 데이터, 상쾌한캡처로 보낸 기록 |
| `20261126_211205_00512.bin` | 장비가 보낸 원본 데이터 |

[출력]이나 [컴퓨터에 보관]을 누른 결과는 여기에 더해 **보관 폴더**에 날짜별, 환자 이름으로 정리된 사본이 생깁니다(위의 "출력" 참고). 저장 폴더는 잃어버리지 않기 위한 곳이고, 보관 폴더는 사람이 찾아보기 위한 곳입니다.

## 그 밖의 명령

| 명령 | 하는 일 |
| --- | --- |
| `python -m tsm300 listen` | 창 없이 명령 프롬프트에서 결과를 받아 저장 (환자 정보 없음) |
| `python -m tsm300 decode 파일.bin --chart 00512 --name 홍길동 --tested "2026-11-26 14:30"` | 저장해 둔 원본 데이터로 결과지를 다시 만들기 |
| `python -m tsm300 shortcut` | 바탕 화면 바로가기 만들기 |
| `TSM300.exe update` | 새 버전이 있으면 받아서 바꿔 넣기 (창의 [업데이트]와 같은 일). `--check` 는 확인만 |
| `python -m tsm300 ports` | 시리얼 포트 목록 |
| `python -m tsm300 capture` | 장비가 보내는 바이트를 해독 없이 그대로 기록 (형식 분석용) |

장비와 통신 형식에 대해 알아낸 내용은 [docs/device-notes.md](docs/device-notes.md) 에 있습니다.

## 개발

```bash
python -m pip install -e ".[dev]"
```

```bash
python -m pytest
```

exe 는 Windows 에서 만듭니다.

```bash
python -m pip install . pyinstaller
```

```bash
python tools/build_exe.py
```

`dist\TSM300.exe` 가 생깁니다. `tools\check_exe.ps1` 은 만든 exe 의 버전, 결과지 그리기, 창 뜨기, 스스로 업데이트하기를 확인합니다. GitHub 에 올리면 같은 일이 자동으로 돌고, 버전 번호(`src/tsm300/__init__.py`)가 새것이면 그 exe 가 Releases 에 올라갑니다.

`tests/data` 의 파일은 실제 장비에서 받은 전송입니다. 병원 DB 와 상쾌한캡처는 테스트에서 가짜(`tests/fakes.py`)로 대신합니다. `src/tsm300/links.py` 는 병원의 VNGLive 프로그램에서 쓰는 조회와 전송 코드를 옮겨 온 것입니다. 화면 테스트는 `QT_QPA_PLATFORM=offscreen` 환경변수를 주면 화면 없이 돌아갑니다.
